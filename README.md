# Alpro massage salon prototype

Presentation prototype for the Alpro massage salon on Lobachevskogo Street in Moscow.

## Included

- animated full-screen hero
- four temporary master portraits
- presentation scenario sections
- responsive mobile layout
- official Alpro logo
- online booking call to action

## Local development

```bash
npm install
npm run dev
```

The current portraits and section copy are placeholders. The production version will use real salon photography, master portraits, verified reviews, Yandex Maps booking and a MAX manager contact.
